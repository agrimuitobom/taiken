# files/ ─ 生徒に配布したいファイルを置く場所

**このフォルダにファイルをコピーするだけで、サイトの「資料ダウンロード」に自動で並びます。**
HTMLを書き換える必要はありません。

## 置き方

```
files/
├── 01_配布資料/          ← フォルダ名が一覧の見出し（カテゴリ）になります
│   ├── ワークシート.pdf
│   └── 記録用紙.xlsx
├── 02_スライド/
│   └── 学科紹介.pdf
├── 03_学科案内/
│   └── 食農科学科パンフレット.pdf
└── お知らせ.pdf          ← 直置きしたものは「その他」にまとまります
```

- フォルダ名の先頭の数字（`01_`）は並び順のためのもので、画面には出ません。
  → `01_配布資料` は「配布資料」と表示されます。
- ファイル名がそのまま画面に出ます。生徒が見て分かる名前にしてください。
- 日本語のファイル名も使えますが、記号（`#` `?` `%` など）は避けてください。

## 反映のしかた

| 配信方法 | 操作 |
| --- | --- |
| `python3 server.py` で配信中 | **ファイルを置くだけ**。ページを再読み込みすれば出ます |
| Apache / nginx などの静的配信 | `python3 tools/make_manifest.py` を実行してから再読み込み |

## 一覧に出ないファイル

次のものは自動で除外されます。

- このREADME、`manifest.json`、`.gitkeep`
- `.` で始まるファイル、`~$` で始まるファイル（Officeの一時ファイル）
- `.tmp` `.part` `.crdownload` `.swp`

## 注意

- ここに置いたファイルは、**校内ネットワークに接続している人が誰でも**
  ダウンロードできます。個人情報を含むファイルは置かないでください。
- 大きな動画などは、当日の回線が混み合う原因になります。
  PDFは書き出し時に「最小サイズ」を選ぶと軽くなります。
