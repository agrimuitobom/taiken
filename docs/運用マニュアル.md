## 資料を当日追加したいとき

`files/` の中にファイルをコピーするだけです。**サーバーの再起動は不要**です。

USBメモリから入れる場合（Pi のデスクトップを使わないとき）：

```bash
cp /media/pi/USB/ワークシート.pdf ~/taiken/files/01_配布資料/
```

別のパソコンから入れる場合：

```bash
scp ワークシート.pdf pi@raspberrypi.local:~/taiken/files/01_配布資料/
```

生徒側は、ページを**再読み込み（更新）**すれば新しいファイルが出てきます。

## 困ったときは

### ページが開かない

| 確認すること | 対応 |
| --- | --- |
| 生徒の端末が校内Wi-Fiにつながっているか | モバイル回線になっていると開けません。Wi-Fiに切り替えてもらう |
| アドレスが合っているか | `http://` から始まっているか（`https://` では開けません） |
| サービスが動いているか | `systemctl status taiken-site` → 停止していたら `sudo systemctl restart taiken-site` |
| PiのIPアドレスが変わっていないか | `hostname -I` で確認。変わっていたらQRを作り直す |

IPアドレスが毎回変わって困る場合は、ルーターのDHCP設定でPiのアドレスを固定するか、
Pi 側で固定アドレスを設定してください。

```bash
# 例：有線LANを 192.168.1.50 に固定する
sudo nmcli con mod "Wired connection 1" ipv4.addresses 192.168.1.50/24 \
  ipv4.gateway 192.168.1.1 ipv4.dns 192.168.1.1 ipv4.method manual
sudo nmcli con up "Wired connection 1"
```

### 「配布ファイルの一覧を取得できませんでした」と出る

ファイルは置いてあるのに一覧が空、という場合はほぼこれです。原因は配信方法によって違います。

| 状況 | 対応 |
| --- | --- |
| ラズパイで `server.py` が動いている | `files/` にファイルがあるか確認。あるのに出ないなら `sudo systemctl restart taiken-site` |
| GitHub Pages など静的配信 | `files/manifest.json` が古い／無い状態。GitHubにpushすれば Actions が自動更新します（Actions タブで結果を確認） |
| 手元でコピーして配信している | `python3 tools/make_manifest.py` を実行する |
| HTMLをダブルクリックで開いた | `file://` では一覧を取得できません。`python3 server.py` を使ってください |

`server.py` で配信しているときは `files/` を直接読むので、`manifest.json` は不要です。

### 「まとめてダウンロード（ZIP）」が出てこない

`files/` にファイルが1件も無いときは表示されません。ファイルを置いてから再読み込みしてください。

静的配信のときはブラウザ側でZIPを作るため、押してから数秒かかります
（ボタンに「準備中… 3 / 6」と出ます）。合計200MBを超える場合は確認画面が出ます。

iPhone / iPad では、ZIPが「ファイル」アプリに保存され、タップして展開する形になります。
うまくいかないときは個別のファイルを保存してもらってください。

### ダウンロードが遅い / 途中で止まる

同時アクセスが多いと回線が混み合います。

- 大きなPDFは書き出し設定を「最小サイズ」にして軽くする
- 動画は当日の配信対象から外し、後日URLで案内する
- グループごとに時間をずらしてダウンロードしてもらう

### 写真を差し替えたのに変わらない

ブラウザのキャッシュが残っています。強制再読み込みしてください。

- スマートフォン：ブラウザのタブを閉じてから開き直す
- パソコン：`Ctrl+Shift+R`（Windows）／ `Cmd+Shift+R`（Mac）

### ポート80で起動できない

```
エラー: ポート 80 は管理者権限が必要です。
```

`sudo` を付けて実行するか、`scripts/install-raspi.sh` でサービスとして登録してください
（サービスなら一般ユーザーのままでも80番が使えます）。

## 終わったあと

```bash
sudo systemctl stop taiken-site        # 配信を止める
sudo systemctl disable taiken-site     # 自動起動もやめる
```

個人情報を含むファイルを一時的に置いていた場合は、`files/` から削除しておいてください。

## メンテナンスの引き継ぎメモ

- サイトの見た目：`assets/css/style.css`（色は先頭の `:root` にまとめてあります）
- 写真：`assets/css/photos.css`
- 文章：各HTMLを直接編集（`index.html` / `dx.html` / `download.html`）
- 配信の仕組み：`server.py`（Python標準ライブラリのみ・追加インストール不要）
- サービス定義：`/etc/systemd/system/taiken-site.service`（元は `scripts/taiken-site.service`）

来年度に使い回すときは、`files/` を空にして日程を差し替えるだけで再利用できます。
